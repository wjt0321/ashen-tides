# 《余烬潮汐》项目文档

## 先看哪份

- [PRD.md](PRD.md) —— 项目主文档，教主拍板只看这一份。
- [RESEARCH_REPORT.md](RESEARCH_REPORT.md) —— Godot 技术与生产执行报告。
- [ASSET_CATALOG.md](ASSET_CATALOG.md) —— 美术、字体、音乐、音效资产与许可证规则。
- [CHECKLIST.md](CHECKLIST.md) —— 项目进行中的唯一进度清单。
- [NEXT_PHASE.md](NEXT_PHASE.md) —— 当前下一阶段计划、范围、退出条件和执行顺序。
- `*_DRAFT.md` —— 历史草稿，仅用于追溯。
- `REVIEW_*.md` —— 交叉审查记录，仅用于追溯。

## 文档权威关系

1. `PRD.md`：产品目标、范围和验收标准。
2. `RESEARCH_REPORT.md`：技术实现和生产方法。
3. `ASSET_CATALOG.md`：资产候选、风格和许可证状态。
4. 草稿与审查文件：只用于追溯，不作为执行依据。

跨文档冲突由项目主理人拍板，并同步修改受影响的正式文档。
