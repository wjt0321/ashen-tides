# 玩家体验交付审计（2026-09-06）

> 审计口径：只计算普通玩家从启动游戏后可见、可操作、可持续推进的能力；CLI、数据文件和自动 smoke 不等于玩家功能完成。

## 结论

当前版本不是 PRD 所描述的完整 Alpha，也不是完成品。准确状态是：**C01–C14 战斗内容原型 + 部分设置/存档/教程 + 程序生成视觉基线**。战斗内核已有较多内容，但玩家外壳和局外系统明显滞后。

## 美术资产等级

`assets/art/` 当前像素图片由项目内 Python 生成器确定性生成，主要用于验证尺寸、剪影、颜色、加载接口和色觉变体。它们属于：

- 程序生成视觉基线 / 可替换占位资产；
- 不是最终商业美术；
- 不是经过外部美术评审的 Shipping 资产；
- 单帧为主，缺少角色、敌人、塔和 Boss 的完整动画生产。

后续文档中的“正式资产”应理解并统一改写为“程序生成视觉基线”，直到单项通过视觉评审、动画完整性、许可证和发行构建验收。

## 已修复的玩家流程缺陷

1. C01 通关后无推进：新增下一关解锁写入和结算面板“下一关”入口。
2. 重开后旧建造节点不可用：重置战斗时同步清除所有建造节点 OCCUPIED 状态。
3. 新增真实路径回归：放塔→重开→原节点再放塔；C01 胜利→解锁 C02→进入 C02→放塔。

## 当前真实可用范围

- C01–C14 战斗关卡数据和核心塔防循环；
- 6 塔、2 英雄、2 Boss 及多种关卡机制；
- 暂停、重开、速度、模块、设置、中英、部分教程；
- 单槽战役成绩、解锁和 suspend 存档；
- 通关后顺序进入下一关（本轮修复）。

## 尚未达到 PRD 的主要范围

- 主菜单、章节地图/选关、新游戏/继续、多存档槽和完整首尾流程；
- C15–C24、Boss 3–6、英雄 3/4；
- 四档难度和完整辅助选项；
- 三棵成长树、英雄等级/天赋；
- 图鉴、成就、剧情和完整结局；
- 正式音乐、环境音和商业质量 SFX；
- 最终商业美术与完整动画；
- 手柄全流程、目标低端机和真人盲测。

## 修复优先级

1. 暂停继续堆关卡，先补主菜单、继续/新游戏、选关、设置和退出的玩家入口。
2. 把现有解锁数据接入章节/关卡选择 UI，并补完整端到端测试。
3. 增加战前简报和英雄选择，让已有两名英雄真正可选。
4. 再恢复 C15–C24 内容生产，同时并行补难度、成长和正式美术生产。
